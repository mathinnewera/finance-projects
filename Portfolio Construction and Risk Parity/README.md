# Portfolio Construction and Risk Parity

Notebook exercises on portfolio returns, rebalancing, and risk-based allocation.

## Notebooks

- [Equal- and value-weighted portfolios](equal_value_weighted_portfolios.ipynb): constructs and plots equal- and value-weighted return indices.
- [Portfolio formation and rebalancing](portfolio_formation_rebalancing.ipynb): examines when stocks enter the return sample and builds a rebalanced equal-weighted index.
- [Risk-parity portfolio](risk_parity_portfolio.ipynb): estimates inverse-volatility risk-parity weights and compares portfolio performance and risk with equal- and value-weighted alternatives.

The notebooks refer to input CSV files (`crsp_sample.csv`, `crsp_sample2.csv`, and `mystock_L2Risk.csv`) that are not included in this folder.
