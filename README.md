# Finance Projects Portfolio

A collection of finance and quantitative-investing coursework projects. The repository brings together analyses of portfolio construction, asset pricing, risk, market anomalies, and Chinese equity markets. Each project folder contains its own README with a short overview and links to the available notebooks, reports, and data.

## Projects

| Project | Focus |
| --- | --- |
| [China A-Share Equity Analysis](<China A-Share Equity Analysis/README.md>) | Chinese market valuation, firm fundamentals, and performance persistence |
| [DJI Data Check, Bollinger Bands, Long-Short](<DJI Data Check, Bollinger Bands, Long-Short/README.md>) | Dow Jones data checks, Bollinger Bands, and long-short strategy exercises |
| [Diagnosing Bull Market Maturity](<Diagnosing Bull Market Maturity/README.md>) | Indicators for evaluating bull-market stages |

## Working with the materials

Most computational work is provided as Jupyter notebooks (`.ipynb`); reports and tabular results are included where available. Open a project notebook in Jupyter Notebook, JupyterLab, or Google Colab. Some notebooks expect source data files or packages that may need to be available in the notebook's working directory; each project README describes the included material and any referenced inputs.

The original analytical files are preserved. File and folder names were updated for clearer project navigation, while filenames cited by the report PDFs were retained.
