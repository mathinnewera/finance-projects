# Two-Pass Regression Test of CAPM

An empirical CAPM exercise using CSI 300 index data and Chinese stock returns. The notebook prepares index and stock data, applies the Jensen, Black, and Scholes approach, forms beta-sorted portfolios, and estimates time-series and cross-sectional regressions.

## Files

- [Results report](ResultsPDF.pdf)
- [Two-pass CAPM notebook](two_pass_capm_regression.ipynb)
- [CAPM regression data](<CAPM Regression Data/>): supporting Excel and Stata files

The report describes the Python notebook results and includes the regression tables and discussion.
