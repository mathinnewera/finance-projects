# Portfolio Risk and Efficient Frontier

Notebook exercises on covariance-based portfolio risk and efficient portfolio selection.

## Notebooks

- [Portfolio variance](portfolio_variance.ipynb): presents the matrix formula for portfolio variance and applies it to a six-stock return set.
- [Efficient frontier and capital market line](efficient_frontier_capital_market_line.ipynb): calculates portfolio moments, explores feasible portfolios, and plots the efficient frontier and CML.
- [Optimization-based efficient frontier](optimized_efficient_frontier.ipynb): uses constrained mean-variance optimization to build an efficient frontier and identify a tangency portfolio, with a comparison to brute-force search.

The notebooks refer to `mystock_L2Risk.csv` and `crsp_sample.csv`; these source files are not included in this folder.
